## 交换友链

想加友链的话，来 [GitHub](https://github.com/Zeroct0) 找我，提供下面几项信息即可：

| 字段 | 说明 |
| --- | --- |
| name | 站点名称 |
| link | 站点地址 |
| avatar | 头像图片直链 |
| descr | 一句话简介 |
